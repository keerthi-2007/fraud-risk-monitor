## AI Disclosure

AI tools, mainly ChatGPT and Claude, were used as supporting resources during the development of this assignment.

### How AI Was Used

**1. Debugging and Troubleshooting**

I used AI to understand and resolve issues that came up during implementation and testing.

- I faced issues with Grafana because the metrics were not being scraped properly. I used Claude to understand the possible causes and debug the issue.
- I encountered several errors while developing and deploying the Streamlit application. ChatGPT helped me identify problems in the code and suggested fixes.
- AI also helped me troubleshoot Docker configuration, dependency issues and errors encountered while running the application.
- I used AI to understand and resolve some GitHub Actions test failures.

**2. Understanding Technical Concepts**

I used AI to clarify concepts that I was not completely familiar with, including:

- How the Streamlit frontend communicates with the FastAPI backend through REST APIs.
- How DVC, MLflow and Docker work together in an MLOps workflow.
- How Prometheus collects metrics and how Grafana visualizes them.
- How model monitoring, feedback, retraining and model version management work.
- How CI pipelines automate testing and help identify implementation issues.

**3. Implementation and Testing Support**

- AI assisted me in writing and modifying parts of the Streamlit application code. I ran the application myself, checked the functionality and made changes wherever required.
- I used AI for assistance with some test cases, debugging test failures and understanding test outputs.
- AI also helped with parts of the retraining and model deployment implementation. I reviewed the code and used tests to check its behaviour.
- I ran the commands and tests on my virtual machine and checked the resulting outputs.

**4. Documentation and Report Preparation**

- AI helped me generate and format the architecture diagrams and design documents. I provided the project details, system components and implementation information.
- AI assisted with organizing and writing the project report using the results, observations and details I provided.
- I reviewed the generated documentation and corrected it to match the actual project implementation.

### Impact

AI was useful throughout the assignment, particularly for understanding unfamiliar concepts, debugging errors, implementation support, testing and documentation.

I was responsible for running the application, executing commands and tests on my virtual machine, checking the outputs and reviewing the final implementation. 

AI generated suggestions and code were treated as supporting material and were reviewed rather than assumed to be correct.
